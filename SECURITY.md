# Security Policy

OpsPilot is an operations and automation portfolio project.

Use the health-check, log-analysis, backup, and integrity commands only on systems, endpoints, files, and logs you are authorized to access.

Do not commit production secrets, API keys, access tokens, private keys, passwords, or sensitive production logs to this repository.

For vulnerabilities in OpsPilot itself, use GitHub's private security advisory feature rather than publishing exploitable details in a public issue.
